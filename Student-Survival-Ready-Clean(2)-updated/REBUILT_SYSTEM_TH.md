# Student Survival — ฉบับเขียนระบบใหม่

## สิ่งที่เปลี่ยน

- หน้าแรกเป็นหน้าต้อนรับสาธารณะ แต่ต้องเข้าสู่ระบบก่อนใช้ฟังก์ชันทั้งหมด
- ก่อนเข้าสู่ระบบจะไม่แสดงเมนู Dashboard และเมนูการเงิน
- พิมพ์ URL ของหน้าภายในโดยตรงก็จะแสดงหน้าเข้าสู่ระบบ
- หลังเข้าสู่ระบบมีเมนูเดิมครบ: Dashboard, การเงิน, No-Spend Day, Emergency Reserve, วิเคราะห์, เป้าหมาย และทีม
- รวมกฎการเงินและการอ่านเขียนข้อมูลไว้ใน `money_store.py` เพียงจุดเดียว
- ทุกรายการและทุกเป้าหมายใช้รหัสถาวร จึงลบได้ถูกต้องแม้มีการเรียงรายการใหม่
- ข้อมูลแยกตามบัญชีผู้ใช้อย่างชัดเจน
- ข้อมูลเก่าที่ไม่มีชื่อเจ้าของจะย้ายให้บัญชีเดิมอัตโนมัติเมื่อระบบมีผู้ใช้เพียงบัญชีเดียว
- รายจ่ายไม่สามารถเกินเงินพร้อมใช้หลังหักเงินสำรอง
- เงินสำรองไม่สามารถเกินยอดคงเหลือ
- ป้องกันวันที่อนาคต ตัวเลขติดลบ `NaN` และ `Infinity`
- บันทึกข้อมูลแบบไฟล์ชั่วคราวแล้วสลับไฟล์ เพื่อลดโอกาสไฟล์ JSON เสีย
- คง Motion UI และ Sidebar เดิมไว้

## วิธีใช้งานบน Windows

1. แตกไฟล์ ZIP
2. ดับเบิลคลิก `setup.bat` ครั้งแรก
3. ดับเบิลคลิก `run.bat`
4. สมัครสมาชิกหรือเข้าสู่ระบบ แล้วจึงใช้งานเมนูภายใน

## ผลการทดสอบ

- ชุดทดสอบอัตโนมัติ 12 รายการผ่านทั้งหมด
- ตรวจการล็อกหน้า การเพิ่มรายรับ การป้องกันเงินติดลบ การย้ายข้อมูลเก่า และการป้องกันแก้ข้อมูลข้ามบัญชี
